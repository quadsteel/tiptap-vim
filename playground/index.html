Vim Cheatsheet

Modes

  • i Insert at cursor
  • a Insert after cursor
  • I Insert at line start (^)
  • A Insert at line end ($)
  • o Open line below
  • O Open line above
  • Esc / Ctrl-[ Normal mode
  • v Visual character mode
  • V Visual line mode

Motions

  • h j k l Left, down, up, right
  • w b e Word start/back/end
  • W B E Big WORD start/back/end
  • f / F Find char forward / back
  • t / T Till char forward / back
  • ; / , Repeat find / reverse
  • % Match pair ((), {}, [])
  • { / } Paragraph up / down
  • 0 / ^ / _ / $ Line start / non-blank / end
  • gg / G Document start / end
  • [count] Prefix (e.g. 3w, 5j)

Operators & Actions

  • x Delete character
  • r{char} Replace single char
  • dd Delete line
  • d{motion} Delete motion (e.g. dw, d$)
  • cc Change line
  • c{motion} Change motion (e.g. cw)
  • yy Yank line
  • y{motion} Yank motion
  • p / P Paste after / before
  • u Undo
  • Ctrl-r Redo
